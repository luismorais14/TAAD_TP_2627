# Qualidade de Fornecedores: Data Warehouse

Trabalho prático de **Tópicos Avançados de Armazenamento de Dados**
(Mestrado em Engenharia Informática, ESTG – Universidade Técnica do Porto, 2026/2027).

Sistema de Business Intelligence para analisar a qualidade de fornecedores, com base em
defeitos de materiais e tempos de paragem de produção. Inclui um Data Warehouse, um processo
de povoamento em arquitetura _medallion_ (Bronze, Silver, Gold), proveniência W3C PROV-O e
dashboards de análise.

A documentação do projeto está na [wiki](../../wiki).
